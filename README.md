# 番茄钟

一个简洁的桌面番茄钟，纯 HTML/CSS/JS 实现，打开即用。

## 功能

- **三种模式**：工作 (25 分钟) / 短休 (5 分钟) / 长休 (15 分钟)
- **自动切换**：工作结束自动休息，每 4 个番茄自动切长休
- **环形进度条**：实时显示剩余时间
- **系统通知**：时间到弹出桌面提醒
- **键盘快捷键**：
  - `空格` — 开始/暂停
  - `R` — 重置
  - `S` — 跳过当前阶段
  - `1/2/3` — 切换到工作/短休/长休
- **番茄计数**：记录今日完成数

## 使用

直接在浏览器中打开 `pomodoro.html` 即可。

```bash
open pomodoro.html
```
